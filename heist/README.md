# Sans Filet

Jeu de braquage à la première personne (Three.js, TypeScript). Tu pars de rien, avec 15 000 $ de dette.
Repère, prépare, frappe : coffres de voiture, supérette, bijouterie, puis la Banque Centrale du Crédit.
Rentre avant les sirènes, fais blanchir ton butin, rembourse.

```bash
npm install
npm run dev
```

Commandes : ZQSD/WASD, souris, E (interagir, maintenir pour forcer), clic droit (braquer), clic gauche
(tirer, frapper, enfiler), R (recharger), C (s'accroupir), Maj (courir), 1–8 (objets), Tab (carnet), Échap (pause).
